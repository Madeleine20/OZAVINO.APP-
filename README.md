# OZAVINO.APP- 


1. Présentation du ProjetNom : Ozavino - Bibliothèque Universelle Afro-descendante.Description : Une application Java Swing permettant de découvrir des auteurs africains, afro-américains et afro-latins à travers une interface interactive de type "Scrapbook".Objectif : Promouvoir la culture littéraire via une interface multilingue (FR, EN, ES).
   
   2. Fonctionnalités (Features)Bookshelf Interactive : Navigation visuelle via une étagère de livres (téléchargement (6).jpg).Book Review : Journal de lecture personnalisé basé sur un design Canva (télécharment (4).jpg).Multilingue : Système de traduction dynamique utilisant un dictionnaire (Map<String, String[]>) .Event-Driven : Utilisation intensive des ActionListeners et MouseListeners pour une navigation fluide
    
   4. Technologies utiliséesLangage : Java.Bibliothèque GUI : Swing (recommandé pour sa portabilité et sa richesse en composants) .Gestion de versions : Git / GitHub.4. Instructions d'installationMentionne que les images doivent impérativement être placées dans le dossier /images.Précise la version de Java nécessaire.
